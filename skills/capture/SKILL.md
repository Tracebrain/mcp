# Write that promise down

One line onto the Tracebrain task list, under the person it is owed to or by.

## Order

1. `find_people` to turn the name into a note stem. A task belongs to somebody
   already in the vault; there is no tool that adds a person, and guessing a
   stem gets a refusal rather than a new page.
2. `add_task` with that stem and one line in the imperative - "send Olena the
   deck", not "I said I'd probably get the deck over to Olena at some point".
3. Say where it landed, so the user can see it on the Tasks screen.

## What to say

Read the line back before writing it when you had to rephrase much. A promise
recorded in words the user would not recognise is a promise they will not act
on.

## Rules

- **The same task twice is refused, not duplicated.** That is the vault
  protecting itself; do not work around it by rewording the line.
- **One promise, one task.** "Send the deck and book the room" is two.
- **Only what the user said.** A task invented from something a model inferred
  is a promise nobody made.
- **No passwords, codes or card numbers in a task.** They stay in the
  conversation; the server refuses a line that looks like one anyway.
